One permission to go

atelier applies your styles with Firefox's user scripts feature: it's the only way to get a style into a page before the page first appears, so you never see it unstyled. Firefox asks for this permission separately, and only with a click.

atelier only runs its own code, which inserts the styles from your atelier directory into the pages they're written for.

Ready

atelier is serving your styles from (theme: ).

To style a site, open it, click atelier's toolbar button, and choose Style this site. An agent session does the work: start one in your agent harness (in Claude Code, atelier's /mcp__atelier__work prompt), or have atelier start one for you with [session] in its config.toml.
